## 当前运行注意事项

- MySQL、Qdrant 和模型 API 仍是本地运行前置条件。
- 后端需要使用当前源码重新启动，才能加载 `page-assets-v3`、`vision-schema-v2` 和 120 秒复杂表格超时。
- 16 篇语料适合开发回归和简历项目量化，不能直接代表大规模生产文献库。
- 用户自己的 `简历描述.txt` 是工作区个人材料，不属于项目文档体系，保持不跟踪。
- 本地代码执行依赖独立 Claude Code / Research Engineering Agent 项目及 localhost Bridge；MyAgent 后端本身不运行用户代码。
- 论文复现当前交付“最小实现 + 基础可运行检查”，不等于自动下载数据、训练模型或复现论文指标。
- 多模态事实已经组装为 `ReproductionSpec` 并加入 Agent Context v2；`MODEL_INFERRED`、低置信度内容和冲突不会作为可信参数发送。Paper 13、38 已完成真实协议联调。
- 独立 Agent 已升级为完整保存 v2 规格、evidence 来源和分级 handoff；`NOT_READY` 在模型调用前暂停，模型轮次达到安全上限时仍会保留代码和恢复交接，不会把未收尾状态伪装为成功。
- Idea 模式必须由用户选择已有代码仓库；本地 RepositoryBaseline 决定允许/禁止修改的路径，绝对路径、源代码和密钥不会同步到 MyAgent。
