# RAG SSE 流式输出计划

> 状态：已完成
> 日期：2026-07-16

## 目标

在保留现有同步 RAG 接口和检索质量的前提下，让前端在模型生成过程中持续看到回答内容，并量化首个回答片段等待时间。

## 实施范围

- OpenAI-compatible 模型客户端支持 `stream=true`，逐行解析 `delta.content`；
- `LlmService` 增加流式能力，Qwen、DeepSeek、智谱复用同一实现；
- 新增 `POST /api/rag/chat/stream` SSE 接口，依次发送阶段、元数据、回答增量、完成或错误事件；
- 同步与流式接口复用同一套检索、Prompt、历史保存和后处理逻辑；
- 前端实时显示本轮问题、生成阶段和逐步增长的回答；
- 完整回答生成后仍保存会话历史，并返回来源和分段耗时。

## 边界

- 不改变 Query Rewrite、召回、重排、Prompt 和模型参数；
- 不删除原有 `/api/rag/chat`；
- 本阶段不实现断线续传，也不承诺缩短模型完整生成耗时；
- 用户主动取消或网络断开时允许停止前端展示，后端错误必须发送明确事件。

## 验收标准

1. 模型客户端能够解析跨缓冲区的 OpenAI SSE 数据并拼接完整答案；
2. 前端在 `complete` 之前至少接收到一个 `delta`；
3. 完整答案与同步调用的数据结构兼容，历史记录、引用和 timing 正常；
4. 原有同步 RAG 及前后端自动化测试继续通过；
5. 用真实单篇和全库问题记录首片段耗时、完整耗时及等待改善比例；
6. 完成报告、状态更新和独立 Git 提交。

## 完成结论

全部验收项已完成。真实单篇和全库用例平均 3,618 ms 出现首段、31,519 ms 完整结束，流式答案与最终答案 100% 一致，平均感知等待减少 84.98%。详见[流式输出评测报告](../../evaluation/reports/rag-sse-streaming-2026-07-16.md)。
